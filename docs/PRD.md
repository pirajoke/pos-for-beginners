# PRD: Sisi Obsidian Starter

## Objective

Create a cloneable starter repo that installs a simple Obsidian vault structure and guides a beginner through setup with AI assistants.

## Users

- Sisi: beginner or client user setting up a practical vault.
- Claude Code / Claude / Codex / ChatGPT: guided interview and vault maintenance assistants.
- Maxim: operator who hands off the repo and adjusts the template for clients.

## Core Outcomes

1. Client can clone/download the repo and run one installer.
2. Installer creates 6-10 clear top-level folders.
3. Client answers setup questions one at a time.
4. Vault contains clear rules for folder placement, naming, source handling, and post-task logging.
5. Vault has safe source destinations for Notion, Mail, Granola, Crisp, Obsidian, and manual context.
6. MCP setup is documented and gated by explicit approval.
7. Agent working agreement can be generated from an interview.

## Non-goals

- Complex Zettelkasten/PARA/GTD system by default.
- Automatic external account connection.
- Email sending.
- Broad mailbox/workspace scraping.
- Secret storage.
- Full dashboard product.

## Acceptance

The system is accepted when a clean vault can be bootstrapped, checked, and used by a client who only follows `START HERE - Sisi Obsidian Setup.md`.
