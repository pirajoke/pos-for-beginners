# Client Install Guide

## macOS

1. Download or clone the repo.
2. Open the repo folder.
3. Double-click `install.command`.
4. Drag your Obsidian vault folder into the Terminal window.
5. Press Enter.
6. Optional: drag a folder with approved source exports.
7. Open `START HERE - Sisi Obsidian Setup.md`.

## First AI Step

Open:

```text
90-Operations/Setup/Claude First Run.md
```

Paste it into Claude Code, Claude, Codex, or ChatGPT.

Answer one question at a time.

## Connecting Sources

Do not connect sources during first install.

When ready, open:

```text
90-Operations/Setup/Connect Sources Prompt.md
```

Connect only one source at a time.
